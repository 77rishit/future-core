# Future Core

Build a highly interactive 3D website for a college Techfest called “TECHFEST 2026”.

Concept: “Enter the Future”

The website should feel futuristic, premium, immersive and visually impressive, like a modern technology conference website.

TECH STACK:

- React + TypeScript

- Tailwind CSS

- Three.js / React Three Fiber for 3D

- Framer Motion for animations

- Fully responsive

DESIGN:

- Dark futuristic background

- Black/deep navy base

- Neon cyan, purple and electric blue accents

- Glassmorphism UI

- Subtle grid patterns

- Glowing borders

- Floating particles

- Modern bold typography

HOMEPAGE:

Create a full-screen hero section with:

- Large title: “TECHFEST 2026”

- Subtitle: “ENTER THE FUTURE”

- Short description: “Where technology meets imagination.”

- CTA buttons: “Explore Techfest” and “View Events”

3D HERO:

Create an interactive 3D futuristic object in the center, such as a glowing technological sphere/core.

- Slowly rotate automatically

- React to mouse movement

- Add floating particles around it

- Add glowing rings orbiting the object

- Make it feel like a futuristic energy core

SCROLL EXPERIENCE:

As the user scrolls:

1. Hero moves away smoothly

2. The 3D core transforms/scales

3. Events section appears with animated cards

4. About section appears with floating 3D elements

5. Timeline section appears with animated glowing lines

6. Registration CTA appears with a strong visual transition

SECTIONS:

1. HERO

“TECHFEST 2026”

“ENTER THE FUTURE”

2. ABOUT

Title: “A Playground for Innovators”

Explain that Techfest brings together coding, robotics, AI, gaming and innovation.

3. EVENTS

Create interactive glassmorphism cards:

- Hackathon

- Robo Wars

- AI Challenge

- Code Sprint

- Gaming Arena

- Innovation Expo

Cards should have hover animations, 3D tilt effects and glowing borders.

4. TECH STACK / DOMAINS

Show floating 3D-style badges:

AI

ROBOTICS

WEB3

CYBERSECURITY

GAME DEV

IoT

5. TIMELINE

Create an interactive futuristic timeline:

Registration → Prelims → Workshops → Competitions → Grand Finale

6. WHY TECHFEST

Show statistics:

50+ Events

2000+ Participants

20+ Workshops

24 Hours of Innovation

Animate the numbers when they enter the viewport.

7. FINAL CTA

Large text:

“READY TO BUILD THE FUTURE?”

Button:

“REGISTER NOW”

Add a large interactive 3D glowing object behind the CTA.

INTERACTIONS:

- Smooth scrolling

- Scroll-triggered animations

- Mouse-follow effects

- 3D card tilt

- Parallax effects

- Hover glow

- Animated particles

- Smooth page transitions

- Micro-interactions on every button

IMPORTANT:

Do not make it look like a generic dashboard.

Prioritize visual impact and the 3D experience.

Keep the interface clean and professional.

The 3D elements should enhance the website rather than make it slow or cluttered.

Add a responsive mobile layout.

Make sure the website actually works and all animations are functional.
